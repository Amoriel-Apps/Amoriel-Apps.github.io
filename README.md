# Amoriel-Apps.github.io

Static site for **Amoriel Apps**, served by GitHub Pages.

- `index.html` — landing page (single file, no build step)

## Local preview

```sh
python3 -m http.server 8000
# then open http://localhost:8000
```

## Publishing

Push to `main`, then in the repo: **Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)`**.
The site goes live at https://amoriel-apps.github.io
